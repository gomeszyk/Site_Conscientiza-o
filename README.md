## 💡 Sobre o projeto

Interface web dedicada à conscientização sobre **racismo, transfobia, misoginia e homofobia**, com informações, dados, referências e orientações para agir.

## ✨ O que está implementado

- Página inicial de apresentação.
- Páginas temáticas sobre racismo, transfobia, misoginia e homofobia.
- Página **Como agir**, com dicas e canais de apoio.
- Navegação entre páginas com React Router.
- Componentes e estilos separados por tema.
- Animações de texto e efeitos de rolagem.

## 🛠️ Tecnologias

React, JavaScript, React Router, Vite, CSS e CSS Modules.

## 🚀 Executar localmente

Instale Node.js e npm:

```bash
git clone https://github.com/gomeszyk/Site_Conscientiza-o.git
cd Site_Conscientiza-o
npm install
npm run dev
```

Para gerar a versão de produção: `npm run build`.
